# Centre Équestre – Site vitrine

Ce projet est un site web moderne pour un centre équestre, réalisé avec React.js et Tailwind CSS.

## Fonctionnalités principales

- Présentation du centre, des activités et de l’équipe
- Pages dédiées pour chaque activité (classique, western, poney club, balades, concours, examen fédéral)
- Galerie photos
- Agenda des événements
- Infos pratiques (horaires, accès, coordonnées)
- Formulaire de contact avec choix de l’activité
- Navigation fluide (SPA) avec React Router
- Responsive et design moderne

## Installation

1. **Cloner le dépôt**

```
git clone https://github.com/MBSylvain/equestre.git
cd equestre
```

2. **Installer les dépendances**

```
npm install
```

3. **Lancer le serveur de développement**

```
npm start
```

Le site sera accessible sur [http://localhost:3000](http://localhost:3000) ou le port indiqué.

## Déploiement

Vous pouvez déployer ce projet sur Vercel, Netlify ou tout autre hébergeur compatible React.

## Structure du projet

- `src/components/` : composants réutilisables (Header, Footer, Hero, ActivityCard, etc.)
- `src/pages/` : pages principales et pages d’activités
- `src/App.js` : configuration des routes

## Personnalisation

- Modifiez les images, textes et coordonnées dans les composants pour adapter à votre centre.
- Ajoutez ou retirez des activités selon vos besoins.
